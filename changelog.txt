# Version 1.0.13+15 Changelog

- **Offline AI Upgrades:** Implemented frequency-weighted Naive Bayes classification for drastically smarter vendor category predictions.
- **Fuzzy Autocorrect:** Added Levenshtein Distance algorithm to perfectly map and learn from OCR typos (e.g. MCDNLD -> McDonalds).
- **Phrase-Based Keyword Learning:** The scanner now learns multi-word phrases (e.g. "GRAND TOTAL") instead of single words for flawless total extraction.
- **OCR Date Parser Fix:** Fixed regex to properly support dates with periods (e.g. 2026.06.07) and strict word boundaries, preventing partial matches from extracting wrong years.
- **Camera Crash Fix:** Fixed a fatal lifecycle crash that occurred when navigating away while the background camera scanner was still capturing.
- **Image Compression:** Added local hardware-accelerated image compression (down to 1080p, 50% quality) to significantly reduce Firebase upload latency and storage costs.
